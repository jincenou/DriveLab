# 首尾异常自动处理：2026-10-24

目标是让流水线自行排除短暂首尾姿态异常，不要求在线 Codex 持续监督，不修改冻结的生成模型和 32999+15000+5000 次重建预算。

规则使用 COCO 检测可信度、SMPL 关节旋转的 SO(3) 帧间距离和按人体框高度归一化的投影残差。中间可信观测建立动作幅度参考；需要持续的可见性下降与拟合异常共同出现。所有系数来自本轮工程开发，并非论文参数或独立测试集调参结果。源码和运行策略记录哈希。长期不可测的某一肢体不再导致整个对象被直接拒绝；该部位仍是 unknown。

首尾合计裁剪上限为 min(原帧数×15%,12帧)，保留至少41帧；正常片段不裁。中间异常、裁剪超限或缺少足够诊断证据的对象单独跳过，队列继续。当前启发式不能保证找出所有异常，也不能用检测通过代替外观验收。
